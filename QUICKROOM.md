# Quickroom architecture

Quickroom is a fast image browser/viewer built on Darkroom's components: a filesystem browser showing image
thumbnails, with Darkroom's image viewer and video player for opening items. It has no library, catalog, or labels.

This file is the architectural entry point for Quickroom. To be written when v1 is done; until then see
[DARKROOM.md](DARKROOM.md) for the shared components.
